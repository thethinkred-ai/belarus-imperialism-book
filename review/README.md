# review/ — промты для авторского рецензирования по главам

Каждый файл `promt-*.md` — готовый промт для рецензии соответствующей главы книги.

## Как пользоваться

1. Откройте промт главы (например, `review/promt-1.md`).
2. Приложите к нему текст главы: `chapters/01-kategorii-i-kriterij.md`
   (или вставьте текст ниже промта, если работаете в чате модели).
3. Ответ модели сохраните как `review/otzyv-<номер>-<метка>.md` — отзывы лягут
   в основу правок v1.0.

## Промт самодостаточен: в нём уже есть

- роль жёсткого внешнего рецензента (стандарт нашей рецензии Морозовой и внешней
  критики v0.6 — включая ловушку «перехода от недоказанности к отсутствию»);
- три уровня претензий: факты / метод / редактура;
- специфические вопросы главы (5–7 штук, сгенерированы из её задач и CHECKLIST.md);
- общие вопросы: чек-лист «анти-Морозова», трассировка [Л-1…Л-5], реестр CLM/SRC,
  правило свежести данных;
- требуемый формат отзыва с вердиктом.
