## Как работать

1. Прочитайте главу целиком (файл указан выше; текст можно приложить к промту или вставить ниже).
2. Пройдите по вопросам этого промта — каждый вопрос обязателен, даже если ответ «вопрос снят, потому что…».
3. Для каждого замечания укажите: место (параграф/предложение), суть проблемы, предлагаемую правку.
4. Отличайте три уровня претензии: (а) фактическая ошибка; (б) методическая слабость (вывод сильнее данных);
   (в) стилистическая/редакционная. Помечайте уровень.
5. Итог рецензии: вердикт по главе — «готова / готова с правками / требует переработки» + список правок
   по приоритету.
