# Рецензия: Приложение В. Как писалась эта книга

> Файл главы: `chapters/prilozhenie-v-kak-pisalas.md` · Статус черновика: v0.6 · Рецензирует: автор книги
> Роль: вы — внешний рецензент марксистско-ленинского проекта. Задача — атаковать текст,
> а не согласиться. Стандарт — тот же, которым проект рецензировал книгу Морозовой и
> которым нас рецензировала внешняя модель (проверка на «переход от недоказанности
> к отсутствию», на подмену категорий показателями, на вывод сильнее данных).

## Как работать

1. Прочитайте главу целиком (файл указан выше; текст можно приложить к промту или вставить ниже).
2. Пройдите по вопросам этого промта — каждый вопрос обязателен, даже если ответ «вопрос снят, потому что…».
3. Для каждого замечания укажите: место (параграф/предложение), суть проблемы, предлагаемую правку.
4. Отличайте три уровня претензии: (а) фактическая ошибка; (б) методическая слабость (вывод сильнее данных);
   (в) стилистическая/редакционная. Помечайте уровень.
5. Итог рецензии: вердикт по главе — «готова / готова с правками / требует переработки» + список правок
   по приоритету.

## Специфические вопросы этой главы

- Фактология отчёта: бюджет $5.54 из $10 (сверить с consultations/LOG.md); модель GPT-6 Astra Pro; две внешние критики (35.9 и 60.7 тыс. знаков) — всё ли точно?
- Границы роли модели: приложение честно говорит, что модель не «писала книгу» — и не скрывает ли при этом реальный вклад режимов (генерация черновиков разделов)?
- Список найденных ошибок: полон ли против фактической истории (недоказанность→отсутствие; «независимые оси»; Белтрансгаз «в счёт долга»; дубль МТЗ в списке 2020; «сознательность» без данных)? Что забыто?
- Честный список лакун: совпадает с заключением и реестром (CLM-028, прямые строки CLM-033, CLM-016 полностью, документирование 2020)?
- Тон: самокритика без самобичевания — укрепляет ли приложение доверие читателя к остальному тексту?
- Безопасность: не раскрывает ли приложение ключи, секреты или внутренние пути?
