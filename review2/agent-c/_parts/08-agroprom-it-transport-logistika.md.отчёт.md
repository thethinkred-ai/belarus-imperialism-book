# Отчёт по 08-agroprom-it-transport-logistika.md

**Вердикт рецензии:** «требует переработки» — ключевые выводы об агропроме, IT и транзитной логистике
сильнее предъявленной доказательной базы; гипотезы о контроле, присвоении и классовом результате были
изложены как установленные факты. Принято: переработаны все четыре P0-замечания, закрыты или смягчены
восемь пунктов чек-листа «анти-Морозова», добавлены обязательные блоки Части VII (миграция, генеративный
ИИ) на требуемой глубине.

## Замечания уровня (а) — факты

1. **Монопсония РФ как факт (п. 1.1)** → [ПРИНЯТО] → §8.2: тезис раздроблен на четыре отдельных
   (рынок / концентрация покупателей / диктат цены / присвоение), каждому — статус; добавлены данные ЕС
   (€151 млн / €1,159 млрд, 2025) как иллюстрация того, что безальтернативность РФ не доказана.
2. **Закупочная и розничная цена ≠ присвоение (п. 1.2)** → [ПРИНЯТО] → §8.2 тезис 4: перечислены
   компоненты разницы (транспорт, хранение, потери, переработка, торговые расходы, налоги); вывод —
   маржа не доказывает ренты без контрфакта; задание на цепочку «закупочная цена → перевозка → опт →
   розница» по 2–3 товарам.
3. **Зарплаты и «административная привязка» (п. 1.3)** → [ПРИНЯТО] → §8.2 «Труд»: требование периода,
   показателя и круга отраслей; номинальная ≠ реальная; занятость в с/х ~9,5% (2025) [SRC-067]; для
   привязки названы четыре разных института-кандидата, статус НЕ ДОКАЗАНО (ОТКРЫТО); межглавная ссылка
   на гл. 6 §6.2/§6.5 добавлена (в прежней версии стоял §6.3, не соответствующий новой гл. 6).
4. **Данные 2021 года не описывают 2026 (п. 1.4)** → [ПРИНЯТО] → §8.3: 31,4% и 6% названы точками
   отсчёта; введены данные ПВТ за 2025 (выручка 8,6 млрд руб., экспорт ~$2 млрд, внутренние продажи
   2,4 млрд руб., ~61 тыс. занятых) [SRC-083] и сохранён ряд ~59 тыс. / пик ~100 тыс. [SRC-070].
5. **«Источник вычета» вместо данных ПВТ 2025 (п. 1.5)** → [ПРИНЯТО] → §8.3: введено разделение трёх
   рядов (занятость / экспорт / локализованная прибыль) с явной оговоркой об «агрегат ≠ контур» и
   добавлена таблица четырёх типов компаний с цепочкой IP → договоры → выручка → прибыль → налоги.
6. **«Транзитная рента рухнула» (п. 1.6)** → [ПРИНЯТО] → §8.4: показатели разнесены на пять строк
   (транзит / экспорт / импорт / внутренний грузооборот / доходы звеньев); внесены данные о падении
   грузооборота 130,842 → 74,045 млрд ткм [SRC-087]; расчёт транзитной выручки — НЕ ДОКАЗАНО (ОТКРЫТО).
7. **Неверный экономический характер транспорта (п. 1.7)** → [ПРИНЯТО] → §8.4 «Категориальная поправка»:
   транспортная услуга продолжает производственный процесс в сфере обращения, транспортный капитал
   создаёт стоимость и получает прибыль; рента — отдельный механизм (дефицитный узел, административное
   право, монополия на маршруте). Классовый вывод смягчён: падение ≠ доказательство ренты.

## Уровень (б) — метод и логика

8. **Неравномерная цепочка доказательства (п. 2.1)** → [ЧАСТИЧНО] → введён явный каркас «показатель →
   отношение → механизм → положение → классовый результат» (§8.1) и статусы по кейсам, но полноценные
   карты доказательства (пять звеньев по каждой отрасли) не помещены — жёсткий лимит объёма (см. ниже).
9. **«Собственный внешний контур отсутствует» (п. 2.2)** → [ПРИНЯТО] → §8.5 «Граница вывода»: вывод
   ограничен тремя рассмотренными кейсами; добавлено, что включённость во внешние цепочки не означает
   иностранный контроль; общая классификация отнесена к гл. 12.
10. **Субъектность в IT (п. 2.3)** → [ПРИНЯТО] → §8.3: вместо вывода об отсутствии субъектности — четыре
    типа компаний и четыре положения; критерии (отношение к средствам производства, контроль, присвоение)
    соотнесены с гл. 13 §13.4; итоговая классификация отложена.
11. **Сводная таблица как готовый результат (п. 2.4)** → [ПРИНЯТО] → §8.5: добавлен столбец «Статус
    доказательства», категорические формулировки заменены («требует проверки», «требует оценки масштаба»,
    «рентный компонент не рассчитан»); дублирующая вторая таблица исходника удалена.
12. **Посредники (п. 2.5)** → [ЧАСТИЧНО] → §8.1: разведены покупатель, подрядчик/брокер и оператор
    перевозки, заданы четыре функции (владение, цена, риск, остаточная прибыль). Полная разборка
    институтов по каждой отрасли не сделана — лимит объёма.
13. **Периодизация (п. 2.6)** → [ЧАСТИЧНО] → §8.5: единая периодизация 2014–2020 / 2021–2022 /
    2023–2026 применена ко всем трём кейсам; тезис об изменении самих отношений контроля зафиксирован
    как НЕ ДОКАЗАНО (ОТКРЫТО) на 2023–2026.

## Плоскость III — ортодоксальный МЛ

15. **«Высокая добавленная стоимость труда» (п. 3.2)** → [ПРИНЯТО] → §8.3: разведены статистический
    показатель на занятого и прибавочная стоимость по «Капиталу».
16. **Транспорт нельзя объявлять непроизводительным (п. 3.3)** → [ПРИНЯТО] → §8.4 (см. п. 7).

## Плоскость IV — формальная и диалектическая логика

17. **Скрытый переход «зависимость → отсутствие субъектности» (п. 4.1)** → [ПРИНЯТО] → §8.1 и §8.5:
    зависимость и контроль разведены; вывод ограничен предметом.
18. **Переход количества в качество (п. 4.2)** → [ЧАСТИЧНО] → пороги (при какой концентрации — монопсония,
    при каком масштабе релокации — потеря контура прибыли) прямо не названы; вместо этого везде стоит
    НЕ ДОКАЗАНО (ОТКРЫТО) и задание на данные. Явная формулировка «порог не установлен» не вставлена —
    лимит объёма.
19. **Противоречие в IT (п. 4.3)** → [ПРИНЯТО] → §8.3: сектор разложен по типам компаний; сохранены
    одновременно экспортная выручка, внутренние продажи и вопрос о переносе прибыли.

## Плоскость V — литературный уровень

20. **Ярлыки до расчёта (п. 5.1)** → [ПРИНЯТО] → §8.1 прямо называет «монопсонию», «эмигрирующий центр
    прибыли» и «рухнувшую ренту» ярлыками, стоящими раньше доказательства; в тексте они не
    используются как результат.
21. **Таблица маскирует неравномерность (п. 5.2)** → [ПРИНЯТО] → §8.5, столбец статусов.
22. **Термины через пример (п. 5.3)** → [ЧАСТИЧНО] → разведены «центр прибыли» (локализация прибыли по
    юридическому и экономическому признаку) и «посредник» (четыре функции); краткое определение ренты
    дано через механизмы (дефицитный узел, административное право, монополия на маршруте).
23. **Публицистическая формула опережает анализ (п. 5.4)** → [ПРИНЯТО] → §8.4: формула «всё рухнуло»
    показана как тотальнее данных, приведён рейс Усть-Луга — Баюйцюань [SRC-088] как контрпример.
24. **Одинаковый финальный блок по отраслям (п. 5, рекомендация)** → [ЧАСТИЧНО] → три блока «установлено /
    гипотеза / данные» были подготовлены и затем сняты как дублирование статусных пометок внутри
    разделов (лимит объёма); статусы и задания перенесены внутрь каждого кейса.

## Плоскость VI — межглавная взаимосвязь

25. **Труд и миграция 6 → 8 → 13 (п. 6.1)** → [ПРИНЯТО] → §8.3 «Миграция»: четыре разных события
    (уезд человека, перенос трудового договора, юридического лица, центра прибыли); критерии соотнесены
    с гл. 13 §13.4; граница предмета (класс белорусов за границей — гл. 13) проведена.
26. **IT 8 → 13 → 14 (п. 6.2)** → [ПРИНЯТО] → §8.3: статус IT не повышается; нормативные следствия
    (переквалификация, рабочий контроль) не выведены в главу — отнесены к гл. 14.
27. **Финансы и вывоз капитала 4 → 5 → 9 → 10 (п. 6.3)** → [ЧАСТИЧНО] → введено различение релокации
    лица, вывоза капитала и локализации прибыли; единая терминология с гл. 9 не согласована (гл. 9 не
    переработан) — см. журнал связей.
28. **Калий и ВПК (п. 6.4)** → [ПРИНЯТО] → глава не дублирует контуры гл. 7 и 11; отличие показано
    через разведение маршрутов и контроля дохода.
29. **Логистика как канал зависимости (п. 6.5)** → [ПРИНЯТО] → §8.4: перенаправление маршрутов названо
    рабочей гипотезой; требуется зависимость от конкретных операторов и контроль над доходом.

## Плоскость VII — современные тенденции

30. **Миграция как анализ, а не сюжет (п. 7.1)** → [ПРИНЯТО] → §8.3 «Миграция»: разведены события, оценка
    dev.by (SRC-089) помечена как выборка опроса, масштаб — НЕ ДОКАЗАНО (ОТКРЫТО); оценки «массовый отток»
    и «эмигрирующий центр прибыли» не используются как факт. По агропрому и транспорту — формулировки о
    мобильности и вывозе занятости с заданиями.
31. **Генеративный ИИ — центральный пробел (п. 7.2)** → [ПРИНЯТО] → §8.3 «Генеративный ИИ»: удар по
    аутсорсинговой модели, данные OECD (2025, семь стран) [SRC-084] и МОТ (2025) [SRC-085] с оговоркой,
    что это не Беларусь; три различия (задача ≠ рабочее место; масштаб — НЕ ДОКАЗАНО (ОТКРЫТО); выигрыш
    получает контролёр контракта и труда).
32. **Платформенная занятость и посредники (п. 7.3)** → [ЧАСТИЧНО] → в §8.3 отмечено, что брокеры и
    площадки не владеют правами на результат и не организуют труд; договорные схемы подрядчиков — задание.

## Спорные места и конфликты со стандартом

- **Правовая дисциплина (п. 6–7 стандарта):** новые источники (Еврокомиссия, OECD, МОТ, отраслевой
  опрос, публикация о транспорте и о рейсе) — не перечневые для РБ, в прил. Г не внесены; прил. Г не
  менялось (read-only), пункт `[РЕДАКТОР]` оставлен координатору.
- **Конфликт со стандартом (Часть III.2):** формулировка «интеллектуальная рента» не используется —
  совпадает с рецензией и стандартом; расчёт отсутствует, поэтому термин не вводится.
- **Конфликт объёма:** жёсткий лимит 100–125% (15 360–19 200 байт) не позволил выполнить рекомендацию
  п. 5 о трёх одинаковых блоках «установлено / гипотеза / данные» и полные карты доказательства
  (п. 2.1). Приоритет отдан P0 и предметам Части VII.
- **Терминология:** заголовки параграфов 8.2–8.4 изменены (нумерация 8.1–8.5 сохранена), поскольку
  прежние заголовки содержали снимаемые обвинения («в монопсонию РФ», «с эмигрирующим центром прибыли»,
  «обрушение»).
- **Перенумерация:** существующие SRC-026/032/033/034/067/070/012/018 и CLM-030…CLM-032 не
  перенумерованы; новые ID — с SRC-083/CLM-084 без дыр в этом файле.
