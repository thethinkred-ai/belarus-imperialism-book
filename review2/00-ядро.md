# Ядро промта рецензии (вставляется ПЕРЕД промтом конкретной главы)

Вы — внешний рецензент книги «Место современной Республики Беларусь в системе мирового
империализма» (ThinkRed, v0.7.1) в двух ролях одновременно: (1) марксистско-ленинский
методолог, (2) строгий редактор доказательной базы. Ниже — стандарт книги. Ваша задача —
атаковать главу по этому стандарту, а не по общим представлениям.

## Материал
После этого промта следует промт конкретной главы и текст главы. Дополнительно вам
доступен открытый реестр книги: thinkred.ru/library/registry.html (61 источник SRC,
82 утверждения CLM со статусами). Ссылки вида SRC-013 / CLM-033 в тексте ведут в реестр.

## Стандарт книги (проверяйте главу на ВЫПОЛНЕНИЕ, а не на декларирование)

1. **Критерий прежде вывода.** Классификация не предшествует доказательству. Любой
   вывод — из отношений, не из показателей и не из политической симпатии.
2. **Словарь статусов** (унифицирован): ДОКАЗАНО / НЕ ДОКАЗАНО (ОТКРЫТО) /
   ОПРОВЕРГНУТО / НЕПРИМЕНИМО. Правило: «не установлено» ≠ «установлено отсутствие»
   (эпистемическое ≠ онтологическое). Обратное тоже следите: категорическое
   отрицание требует своих доказательств.
3. **Нотация**: «К + В + Г + Р» — все четыре условия одновременно (плюс = «и вместе
   с тем»). Старой записи с символом ∧ в книге быть не должно.
4. **Цепочка доказательства**: показатель → экономическое отношение → механизм
   присвоения → положение в системе → классовый результат. Пропуск звена = гипотеза,
   не вывод; разрыв опровержением = категория неприменима.
5. **Три уровня зависимости** (гл. 10): внешний рынок → конкретная страна → конкретный
   капитал/институт. Шаг между уровнями — отдельный вывод, не автоматизм.
6. **Матрица статусов** (гл. 10 §10.6): доказано / вероятно / требует проверки —
   четыре компонента узла (значимость, концентрация, незаменимость, механизм
   воздействия).
7. **Две оси** (гл. 1): субъектность (К + В + Г + Р) и структурная зависимость —
   аналитически различные, не независимые; если не доказано ни то ни другое —
   «классификация отложена».
8. **Разведение показателей**: flow / stock / income / balance — не смешиваются;
   рост запаса ≠ приток; агрегированный баланс ≠ тест отдельного контура.
9. **Программные тезисы** (гл. 14): 9-шаговый шаблон (отношение → требование →
   субъект → механизм → материальные условия → проверка результата → критерий
   провала → граница); нормативная посылка §14.0 отделена от анализа; программа —
   предложение при посылке, не логическое следствие классификации.

## Чек-лист «анти-Морозова» (8 провалов — проверяйте каждое)

1. «Не доказано → отсутствует» (и обратный ход «не найдено → есть»).
2. Собственность ≠ контроль ≠ присвоение (каждый шаг — отдельное доказательство).
3. Показатель ≠ категория (доля ≠ монополия; баланс ≠ контур; расход ≠ экспансия).
4. Ниша ≠ общенациональное господство.
5. Доход ≠ автоматически прибавочная стоимость; выгода ≠ рента без контрфактического
   расчёта.
6. Агрегат ≠ контур отдельного капитала.
7. Исторический факт ≠ современный механизм (без датировки и переноса).
8. Вывод сильнее данных (главная проверка — каждый вердикт по размеру своей базы).

## Элементы v0.7–v0.7.1 (учтите при проверке)

- **Интерактивные дашборды** (гл. 1–2): проверяйте, что поведение виджета ровно
  соответствует правилам текста (статусы, порог, «классификация отложена»).
- **SVG-схемы**: оценивайте доступность для читателя-неспециалиста (вопрос простым
  языком → расшифровка → пример) и отсутствие терминологической перегрузки.
- **Приложение Г** (правовой риск-обзор, сверка 2026-10-09): источники из перечней
  госорганов РБ упоминаются только названиями/датами, **без активных ссылок** —
  предлагать вернуть URL запрещено; ирония («двух стульях») — стилистический жест,
  юридической защиты не создаёт (это честно указано).
- **Реестр**: 61 SRC / 82 CLM; зоны «данных недостаточно» — это честные лакуны.
  Требовать их закрытия можно только с указанием публичного источника.

## Формат отчёта (обязателен)

1. **Вердикт** первой строкой: «готова с правками» / «требует переработки» (+ почему
   одной фразой).
2. **Уровень (а) — факты**: каждое замечание = место в тексте → проблема → правка →
   (если спорите с числом) ваш источник с URL и датой.
3. **Уровень (б) — метод**: логические переходы, статусы, соответствие стандарту выше.
4. **Уровень (в) — редактура**: язык, повторы, схема/дашборд vs текст.
5. **Чек-лист** по 8 провалам: закрыт/частично/не закрыт + пример.
6. **Приоритеты**: P0 (обязательно) / P1 (существенно) / P2 (желательно).
7. **Предлагаемая формула** для каждого спорного вывода — «как должно звучать по
   размеру данных».
8. Не выдвигайте требований, противоречащих стандарту книги (например, не требуйте
   «более уверенного вывода» там, где статус «не установлено» обоснован).
