**Вердикт рецензии:** «Требует переработки» — глава задаёт сильный методологический стандарт, но не полностью обеспечивает воспроизводимость правил и их применение ко всей книге (разрыв между правильными правилами и доказательством их соблюдения).

## По-замечанийный разбор

**1.1 / Версия главы не совпадает с заявленной → [ПРИНЯТО].**
Блок статуса обновлён до «черновик v0.8 (рецензии review2 применены: …)» — правка синхронизирует версию и перечисляет ключевые правки (rule 10). Проверяемая редакция v0.6 → актуальный исходник уже был v0.7; итог — v0.8.

**1.2 / Маркеры незавершённой доказательной базы (`[источник: …]`) → [ПРИНЯТО].**
Все маркеры `[источник: …]` убраны. Заменены: §2.3 (очистка ПИИ) → `(SRC-013)`; §2.4 (точка 2007) → `(SRC-013)` + `[задание]` на первичный текст договора; §2.6 (перечень источников) → `(SRC-012 … SRC-025)`, а непокрытые отчёты компаний — `[задание]`. Без самостоятельного назначения новых SRC (rule 8).

**1.3 / Периодизация: «крупнейший разрыв» — сравнительный вывод без критерия → [ПРИНЯТО].**
В §2.4 гипотеза 2022 переписана: «крупнейший разрыв потоков» → «один из наиболее существенных структурных разрывов, подлежащих проверке (перенастройка потоков, а не исчезновение торговли)». Оценка ослаблена до проверяемой гипотезы (P1).

**1.4 / Миграция и ИИ: разграничение источников и статусов → [ПРИНЯТО].**
Добавлено правило: конкретные оценки помещаются в эмпирические главы с датой, источником и статусом; методологическая глава фиксирует только правила анализа (см. 7.1, 7.2).

**2.1 / Пять звеньев ≠ пять числовых показателей → [ПРИНЯТО].**
§2.1 переформулирован: «обязательный протокол анализа — последовательность вопросов, а не пять обязательных числовых показателей»; добавлено «статус каждого звена устанавливается отдельно; … итоговый вывод маркируется как гипотеза либо остаётся открытым». Требование к дашборду цепочки (статус каждого звена, а не один итоговый цвет) зафиксировано текстом.

**2.2 / Правило перехода между статусами → [ПРИНЯТО].**
В §2.1 добавлена таблица «Переход / Минимальное требование / Если требование не выполнено» (показатель→отношение; отношение→механизм; механизм→положение; положение→классовый результат), с оговоркой «не универсальный алгоритм автоматического доказательства» (P0).

**2.3 / Вывоз капитала нельзя сводить к запасу + доходу → [ПРИНЯТО].**
§2.3 «Потоки vs запасы» переписан по предлагаемой формуле: потоки/запас/доход анализируются раздельно; для вывода о вывозе капитала устанавливаются форма вложения, собственник/контролирующий субъект, механизм получения дохода, связь с воспроизводством капитала; «ни поток, ни запас, ни доход по отдельности не являются достаточным доказательством».

**2.4 / Чистая позиция ≠ баланс присвоения → [ПРИНЯТО].**
§2.3 «Валовые vs чистые позиции» переписан по предлагаемой формуле: чистые показатели — агрегированный баланс; валовые — масштаб встречных операций; для присвоения нужны субъекты, формы вложений, доходы, механизмы контроля.

**2.5 / Очистка ПИИ не универсально выполнима → [ПРИНЯТО].**
§2.3 «Идентификация транзита в ПИИ» дополнен трёхчастным различением (выделенные в статистике / оцениваемые по доп. источникам / неотделимые) и правилом «остаток нельзя автоматически трактовать как реальное вложение либо как фиктивный капитал».

**2.6 / Шесть вопросов или семь → [ПРИНЯТО].**
В §2.2 контроль условий доступа выделен в отдельный **седьмой вопрос** (кредит, инфраструктура, технологии, рынки, разрешительные механизмы), вопрос 4 оставлен только про распределение; добавлена оговорка «контроль условий доступа — отдельный механизм, не тождественный присвоению прибавочной стоимости». §2.8 п. 2 обновлён («семь вопросов»).

**2.7 / Сравнительные случаи — план, а не валидация → [ПРИНЯТО].**
§2.5 дополнен: «до завершения их анализа они не считаются подтверждением валидности критерия — это план сравнительной проверки, а не её результат»; наличие «независимых оснований ожидать результата» не делает классификацию самоочевидной; перечислено, что показывается по каждому случаю в гл. 12 (признаки, источники, статусы К, В, Г и Р, результат, неоднозначные случаи).

**2.8 / Периодизация: даты ≠ периоды → [ПРИНЯТО].**
В §2.4 добавлен минимальный протокол проверки структурного сдвига (заранее определённые ряды; исходный период; разрывы методологии и пропуски; различение шока и устойчивого изменения; открытость гипотезы при противоречивых рядах).

**3.1 / Глава понятна специалисту лучше, чем новому читателю → [ПРИНЯТО].**
В §2.1 добавлен сквозной пример на одном предприятии (показатель → отношение → механизм → положение → классовый результат), с оговоркой «сопровождает терминологию, а не заменяет теоретическое определение».

**3.2 / Дашборд 2.1 не должен создавать иллюзию формального доказательства → [ПРИНЯТО].**
В §2.1 зафиксировано требование: статус каждого звена с обоснованием, без одного итогового цвета; заполненность ячейки ≠ доказанность перехода; незаполненное звено нельзя автоматически считать доказанным.

**3.3 / Дашборд 2.2: формула запаса и порог 50% → [ПРИНЯТО].**
После `{{WIDGET:flowstock}}` добавлена оговорка: схема запас(t+1)=… — упрощённая; состав зависит от методологии источника; порог 50% переоценки — технический порог интерфейса (эвристика), а не экономический закон.

**3.4 / Технические и терминологические шероховатости → [ПРИНЯТО].**
(а) повтор нумерации `1.` — в исходнике v0.7 списки нумерованы корректно (проверено), правка не требуется; (б) символ `∧` — в исходнике отсутствует (проверено grep), а нотация «К-В-Г-Р» в §2.4 приведена к канонической «К + В + Г + Р» (rule 4); (в) «статистика лжёт» — заголовок §2.3 уже нейтрален («Различения, без которых статистику легко интерпретировать ошибочно») и фраза «Статистика сама по себе не „лжёт“…» объясняет источник проблемы.

**4 / Ортодоксальный марксизм-ленинизм: категориальная дисциплина → [ПРИНЯТО].**
В §2.7 добавлен блок «Что этот метод не позволяет заключать автоматически»: госсобственность/госконтроль ≠ общественное присвоение; экспортная концентрация ≠ монополия в ленинском смысле; прибыль/налоги/разница — прокси прибавочной стоимости, а не сама прибавочная стоимость; К + В + Г + Р — авторская операционализация, а не готовая ленинская формула (P1).

**5 / Формальная и диалектическая логика → [ЧАСТИЧНО].**
Выполнено в части гл. 2: принцип «заполнение схемы ≠ обоснованность переходов» закреплён (§2.1 таблица переходов, §2.8 п. 7); диалектическая периодизация через отношения, а не даты — усилена протоколом §2.4. Межглавная сверка статусов («открытое в гл. 2 не становится доказанным в гл. 9/12 без объяснения») — вне правки самой гл. 2, фиксируется для координатора и эмпирических глав.

**6 / Межглавная взаимосвязь → [ПРИНЯТО].**
Таблица рецензии — план проверки гл. 3–14, а не правка текста гл. 2; рамка гл. 2 уже задаёт проверяемость (возврат отраслевых сюжетов к вопросам воспроизводства §2.2; различения §2.3). Текст гл. 2 не менялся сверх сделанных правок — правка рецензии не вводит в гл. 2 новых данных.

**7.1 / Трудовая миграция и эмиграция → [ПРИНЯТО].**
В §2.2 добавлена предлагаемая вставка: воспроизводство рабочей силы вне национальных границ; различение эмиграции/временной трудовой миграции/трансграничной занятости; демография не отождествляется с миграцией; влияние на предложение труда — по отдельным показателям; конкретные оценки — в гл. 6, 8, 13.

**7.2 / ИИ и трудовые отношения → [ПРИНЯТО].**
В §2.6 добавлена предлагаемая вставка: различение технической возможности задачи / фактического внедрения / изменения организации труда / наблюдаемых последствий для занятости; «нельзя заранее объявлять ИИ причиной сокращения занятости»; конкретные оценки — в гл. 6, 8, 11, 14.

**8 / Чек-лист «анти-Морозова» → [ЧАСТИЧНО].**
По гл. 2 усилены релевантные правила (провал 3 — таблица переходов; провал 6 — чистая позиция ≠ присвоение; провал 4 — план vs результат сравнительной проверки; провал 2 — контроль доступа ≠ присвоение). Окончательное закрытие чек-листа по построению зависит от соблюдения правил в гл. 3–14 — рецензия сама не требует объявлять пункты закрытыми только на основании декларации.

**9 / Приоритеты исправлений → [ПРИНЯТО].**
P0: все выполнены (версия; седьмой вопрос; определения вывоза капитала и чистой позиции; правило перехода; план vs результат сравнения; отсутствие `∧` подтверждено; маркеры `[источник]` сняты). P1: таблица переходов, процедура сдвигов, правила потоков/запасов/доходов, миграция и ИИ, статус авторских операционализаций — выполнены. P2: сквозной пример, пояснения дашбордов 2.1/2.2, порог 50% — выполнены.

**10 / Итоговая формула методологического стандарта → [ПРИНЯТО].**
Добавлена в §2.8 п. 7 (метод задаёт порядок проверки, но не гарантирует результата; статус каждого звена отдельно; неполнота ≠ отрицание; заполненность ≠ доказанность; сравнительные случаи не заменяют доказательство по Беларуси; открытый статус классификации).
