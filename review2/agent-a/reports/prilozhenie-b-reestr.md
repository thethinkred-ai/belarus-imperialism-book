# prilozhenie-b-reestr.md — отчёт по замечаниям рецензии

**Вердикт рецензии:** требует переработки — приложение Б содержит полезное объяснение
доказательной методики, но опубликованная версия отстаёт от реестра (34 SRC / 53 CLM
против актуальных 62 SRC / 83 CLM), а словарь статусов и перечень источников не
согласованы с текущей структурой данных.

По каждому замечанию:

**1 / P0. Устаревшие счётчики и перечень источников (34 SRC / 53 CLM; §Б.2 повторяет 34; §Б.6 до SRC-034 + SRC-054) → [ПРИНЯТО].**
§Б.1 обновлён до 62 SRC / 83 CLM с пометкой «актуальное — в реестре»; повтор «34» в §Б.2 убран; статический «полный список» в §Б.6 заменён ссылкой на реестр (registry.html, `sources/registry.json`). Подпункт «отсутствие SRC-035 — не ошибка нумерации» учтён: в §Б.1 объяснение пропусков сохранено и усилено (пропуски не переиспользуются, ссылки разрешаются однозначно).

**2 / P0. Словарь статусов приложения не совпадает со стандартом книги → [ПРИНЯТО].**
§Б.5 переписан: разведены два уровня — (1) статус карточки CLM в реестре (подтверждено / частично / не проверено / опровергнуто / мониторинг) и (2) четыре итоговых статуса вывода книги (ДОКАЗАНО / НЕ ДОКАЗАНО (ОТКРЫТО) / ОПРОВЕРГНУТО / НЕПРИМЕНИМО); добавлена инструкция перехода от карточки к выводу («частично» ≠ «не доказано»; «не проверено» ≠ «нет данных»).

**3 / P0. Пример CLM-033 актуализировать → [ПРИНЯТО].**
§Б.4 дополнен текущим состоянием (статус «подтверждено», кросс-чек GNI−GDP) и границей вывода по формуле рецензии: подтверждены знак и масштаб агрегатного сальдо, но не получатели потоков, не механизмы присвоения, не принадлежность выплат отдельному капиталу.

**4 / P0. §Б.5 не описывает текущую схему реестра (колонки «ID», «Главы», «Статус», «Текст», «Источники») → [ПРИНЯТО].**
§Б.5 описывает поля карточки и значение колонки «Главы» для межглавной трассировки; §Б.7 перечисляет колонки реестра; явно зафиксировано: отсутствие прямой привязки к источнику = незавершённая трассировка, а не отсутствие данных и не опровержение.

**5 / P1. Политика ссылок «по запросу» должна быть объяснена → [ПРИНЯТО].**
Тематическая карта источников (§Б.3) сохранена, статический «полный список» убран; в §Б.2 и §Б.3 добавлено: актуальные названия/статусы/ссылки проверяются в реестре, часть библиографических сведений — по запросу (прил. Г). Новые URL/имена перечневых источников не вводились.

**6 / P1. Проверить описание CLM-067–082 → [ПРИНЯТО].**
Добавлен блок «Новые группы данных» (§Б.3) и тематическая карта утверждений (§Б.6) — без шестнадцати отдельных длинных описаний; соответствие групп проверено по реестру (SRC-055…067, 069…082).

**7 / P0. В задании CLM-067–082, но реестр уже содержит CLM-083 → [ПРИНЯТО].**
В приложении диапазон не фиксируется: §Б.6 даёт карту с указанием «CLM-079, 083» и оговоркой, что реестр обновляется. Правка промта (замена диапазона) — вне области данного раздела: промт-прил-Б.md не редактирую (фиксирую для координатора).

**8 / P1. Добавить тематическую карту новых утверждений → [ПРИНЯТО].**
§Б.6 — таблица 7 тематических групп (по рецензии), сверенная с фактическими карточками CLM-067–083; с оговоркой «карта для навигации, не доказательство».

**9 / (б) Ортодоксальный МЛ: надёжность источника относительно типа утверждения → [ПРИНЯТО].**
§Б.5: правило, что статистика/документ/первоисточник/публикация выполняют разные доказательные функции; источник, подтверждающий показатель, не подтверждает политэкономический вывод.

**10 / (б) Формальная и диалектическая логика: 5-шаговый след изменений; статус не должен автоматически усиливать вывод → [ПРИНЯТО].**
§Б.4: логика CLM-033 распространена на весь реестр (5 шагов изменения); явно зафиксирован запрет автоматического усиления вывода при изменении статуса.

**11 / (б) Литературный уровень: перегружен устаревшими техническими подробностями; оптимальная структура из 5 пунктов → [ЧАСТИЧНО].**
Содержание применено: убран ручной список, убрано дублирование §Б.1/§Б.2/§Б.3/§Б.6, карта источников сделана компактной, история версий оставлена как схема «три состояния + пять шагов». Порядок разделов сохранён (§Б.4 CLM-033 стоит перед §Б.5 статусы) ради правила «не ломать нумерацию параграфов» — перестановка по предложенной рецензией последовательности не выполнена намеренно.

**12 / (б) Межглавная взаимосвязь: инструкция по чтению связанных CLM → [ПРИНЯТО].**
§Б.6: четыре цепочки (калий; ВПК и сила; труд и миграция; финансы и долг) с указанием, какие различения каждая сохраняет.

**13 / (б) Современные тенденции (миграция и ИИ) → [ПРИНЯТО].**
§Б.6: пример «эмиграционная волна ≠ масштаб изменения классовой структуры и ≠ наличие/отсутствие эмигрантских организаций»; правило входа новых тем (включая ИИ) в реестр только после определения тезиса/типа/источников/ограничений — без неподтверждённых утверждений об ИИ.

**14 / Чек-лист «анти-Морозова» (8 провалов) → [ПРИНЯТО].**
Диагностические замечания закрыты в §Б.5 явным списком четырёх различений (отсутствие данных ≠ отсутствие явления; агрегат ≠ контур; историческое ≠ современное; карточка ≠ вывод) и правилами «показатель ≠ категория», «доля ≠ монополия», «выгода ≠ рента без контрфакта», «ниша ≠ общенациональное господство», «как ограничивать формулировку при частичном подтверждении».
