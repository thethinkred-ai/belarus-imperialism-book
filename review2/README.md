# Новые промты рецензирования (цикл v0.7.1 → v0.8), 2026-10

Старый цикл (папка `review/`) применён полностью: главы 1–14, заключение и приложения
переработаны, сбор недостающих данных выполнен, добавлены приложение Г и интерактивные
дашборды. Эта папка — промты для **нового** цикла рецензий с учётом всех исправлений.

## Как пользоваться

1. Откройте `00-ядро.md` — это общий стандарт (роль рецензента, словарь статусов,
   чек-лист «анти-Морозова», формат отчёта, ориентиры свежести).
2. Возьмите промт нужного раздела из этой папки.
3. Склейте: `00-ядро.md` + промт раздела + **полный текст главы**
   (веб-версия: thinkred.ru/library/bel-gXX.html; в репозитории: chapters/*.md).
4. Отправьте модели; полученную рецензию сохраните в эту папку под именем
   `Рецензия <раздел>.txt` — как в прошлом цикле.
