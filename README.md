# Место современной Республики Беларусь в системе мирового империализма

Исследовательская книга (брошюра ~200–250 стр.) по конвенциям ThinkRed.
Цель — определить место современной Беларуси в системе мирового империализма
на основе ленинской теории и **строгого критерия классификации, построенного до эмпирики**,
а итог — обоснование программных положений независимой коммунистической партии
рабочего класса Беларуси (существующая КПБ анализируется как государственно-встроенная структура).

## Принципы

1. **Критерий прежде вывода** — теоретический критерий (центр / участник / зависимая /
   промежуточная страна) строится в гл. 1 до эмпирики; вывод вытекает из критерия.
2. **Политика из экономики** — экономический анализ (гл. 1–12) → классовый анализ (гл. 13) →
   программные выводы (гл. 14). Тезис включается только с явной цепочкой
   «экономическое отношение → классовая позиция → политическое требование».
3. **Партия как гипотеза** — независимая компартия рабочего класса рассматривается
   как необходимый, но отсутствующий субъект; книга даёт исследовательское обоснование
   её будущей программы.

## Чек-лист «анти-Морозова»

Провалы книги Морозовой (по рецензии thinkred.ru/blog/retsenziya-mesto-rossii-v-imperializme.html),
которые закрыты архитектурно — см. `CHECKLIST.md`. Кратко: явный критерий классификации;
цепочка «показатель → отношение → механизм присвоения → положение → классовый результат»;
модель госкапитализма; ВПК экономически; зависимость ≠ отсутствие собственных интересов;
таксономия зависимости; «центр» vs «участник»; программные тезисы только выводимые.
