## Правила издания брошюры

1. Без активных URL на перечневые источники РБ (прил. Г части I, §Г.3–Г.5).
2. Нейтральная терминология о военных действиях («военные действия на Украине»).
3. Без персонализации автора; ссылки на часть I — «часть I, гл. N / §N.M»
   (нумерация глав части I сохранена: гл. 1–12).

   (`sources/registry.json`, для брошюры — печатное приложение или ссылка по запросу).
